# 清楚直接的语言编辑

正文先把当前问题、推理和证据讲完整。保留使结论成立的条件、实际权衡与不利结果；删去未增加理解的重复免责、空泛评价和自我限定。不因追求简短截断必要解释，也不机械删除“可能”“不能”等词。

以完整段落检查指代、因果和重复。译文、原式、引文与数值不随润色改写。例子与比喻就地帮助认识，自拟数字简明注明教学设定，不为每段重复提示。

核心原则已内置[日常创作](reader_workflow.md#阅读与写作)和[答疑指南](answer_worker_guide.md)，在首次生成中应用。本文件仅供用户专门要求阅读器文字润色或风格分析时按需查阅；按用户指定范围直接修改，不增加默认语言编辑agent、第二遍全文润色、评分或批注全文重载。确需完整语言编辑方法时，再读取[内置原版](../vendor/anti-defensive-writing/SKILL.md)；原资源和来源清单保持保留。
