# 中文静态方法图：结构与绘制

默认采用科学对象示意与[draw-science 阅读器精简模式](visual_authoring_guide.md)：把图当作科学关系的表达，让对象、局部变化和拓扑承担信息。先在当前思考中确定读者应看懂的关系、输入/输出对象、真实模块与连线，随即制作最终资产，不另写图形计划、合同或审核表。

## 先选结构和表达对象

| 实际关系 | 合适表达 | 应避免 |
|---|---|---|
| 顺序变换 | 单向主链，关键中间对象可见 | 把每一行算法拆成一个框 |
| 多路输入/并行计算/融合 | 对齐支路、明确汇合端口、流的身份一致 | 把并行依赖画成前后串联 |
| 编码解码/多尺度/跳连 | 有意义的空间层级、相应尺度对齐、跳连走廊 | 所有网络都画成同一排等大的卡片 |
| 迭代/优化/控制 | 初始化与循环体分区、停止条件、外侧反馈 | 用蛇形排版代替反馈或隐藏停止条件 |
| 机制或复杂模块 | 总体关系加局部放大，具体对象/几何关系可见 | 只有标题框、装饰图标和大段文字 |

模块粒度由功能决定：计算相似度/汇总/选择可合为“建立对应关系”，但不能合掉不同职责、关键创新或真实分支。总图不承担所有推导。数值趋势、实验比较用原图或标准绘图库，不用流程框或装饰小柱图代替数据。

用图像、网格、矩阵/特征、集合或其他准确图元表现真实对象；图元内形状须有含义，教学对象注明“示意”。纯程序动作可用简短文字。既有对象图与新图元不重复堆叠。颜色编码对象/支路/重点，通常少量低饱和色即可；核心关系清楚比颜色数量或圆角风格重要。

两个样式锚点：[DUSt3R 图2](https://arxiv.org/pdf/2312.14132)用对齐双路、共享权重标识和几何输出表达跨视图关系；[U-Net 图1](https://arxiv.org/pdf/1505.04597)用尺度层级和跳连表达编码解码。借鉴它们让图形本身承载关系的做法，不复制其科学模块或把所有对象缩成框内小图标。核心模块必要时展开为真实张量、几何对象或算子关系，普通步骤保持简洁；这些链接供设计参考，不要求每篇重读论文。

## 几何与显示尺度

以下是本阅读器的工程默认值，不是 CVPR 或出版行业的统一规范：

- 按实际显示宽度设计；以 960 px 为工具默认，窄阅读面板应传实际宽度。普通中文标签折算后尽量不小于 12 px，模块标题至少约 14 px。字号不够就缩短说明、改分区/布局，不能把整图继续缩小。
- 先放节点和文字区，再留连接走廊。同行/同层对齐，模块内标题、图元、说明分区；最多保留两行短说明，详细推导留正文。图外留边，分组背景和标题也算障碍。
- 相同重要程度的主连线保持线宽和箭头头部一致，屏幕线宽可从 1.2–1.8 px、头部长 6–8 px 起步。不同连线无需等长；短边仍须有清楚的轴干，末段一般至少容下两倍头长。空间不够就增大间距/改端口，不缩成只有三角形。
- SVG 箭头应显式使用 markerUnits="userSpaceOnUse"（或同样能控制绝对尺寸的实现），统一头部与线宽，避免默认 strokeWidth 单位再次放大。普通线、图元内部箭头和反馈不能各用一套失控比例。
- 连接从语义节点边界/端口出入，不能穿过文字、公式、图元、无关节点。优先直接连线，其次简单正交走线；反馈绕外侧，不用多余小折线。箭头标签放空白处，不能压在线、头部或正文上。
- 区分必要步骤、可选增强、训练/推理、数据流/控制/约束，不暗示未经原文支持的依赖。科学语义由当前作者判断，几何检查不能代替它。

## 结构简图的几何工具（按需）

关系本身足够抽象、无需更具体的对象变化时，可用本地工具处理主链、并行汇合和反馈几何。它是局部辅助，不把等大卡片与重复小图标作为新稿的默认视觉风格：

```sh
python scripts/render_method_figure.py --input <论文目录>/assets/method-figure.json --output <论文目录>/assets/method-framework.svg --display-width 640 --strict
```

配置只描述最终图：title、nodes 和 edges。node 含 id,label，可有 detail（短字符串或两行数组）、glyph，以及全部节点一致填写的 column,row；不写位置时自动分层。edge 用 source,target,kind,label?，kind 为 flow/branch/feedback/dependency。可用 groups:[{id,label,nodes:[节点ID]}] 分区。glyph 可选 none/mesh/matrix/feature/input/output/input-output。不承诺支持未实现的图元。

按需打开一个最接近的[串联样板](../assets/content-templates/method-figures/pipeline.json)、[并行汇合样板](../assets/content-templates/method-figures/parallel-fusion.json)或[反馈样板](../assets/content-templates/method-figures/iteration.json)。它们是合成教学关系，不是论文结论；不要同时加载全部样板，也不要照搬它们的科学模块。

三个样板带窄面板主题 `theme:{canvas_min_width:640,node_width:160,column_gutter:54,margin:24}`。640 是常见阅读面板的起始假设，交付时按实际尺寸传值；宽幅图可改用工具默认960。样板与工具默认字号、线宽、头部大小都是可调整 token，不是只能采用的视觉风格。

工具统一节点、端口、走廊与 marker，返回有界几何摘要；若输出 issues，只修相关字号、间距或路径。超宽/标签过密时由作者改布局或拆清楚，不把全部节点强塞进去。它会绕开节点，但不保证避开所有组标题、边标签和边边交叉，这些仍需在局部渲染中判断。复杂空间机制、密集网络、多尺度结构超出能力时选合适的原图、矢量/布局工具或自绘 SVG，沿用上述约束，不能修改科学关系迁就工具。

## 一次局部显示确认

正常情况下复用工具摘要和一次目标尺寸渲染，纳入日常交付已有截图额度，不另开审阅、打分或多轮强制检查。摘要能检查比例和几何，渲染用来看真实中文字体、字形宽度和布局；发现具体错误才修该处。只返回问题位置或计数，禁止回传整篇正文。默认不加载外部绘图 skill 或调用生成/审阅 API。

其他局部演示只有追踪对象、切换条件或参数变化确需操作时才用现有受控交互类型；静态总图不恢复为交互组件。教学数据与真实实验区分，未测量数值不画成实验结果。
