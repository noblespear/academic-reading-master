# draw-science 阅读器精简模式

本文件是学术阅读任务的新绘图入口，采用draw-science 的科学对象、拓扑、图元、布局和连线原则。阅读器任务以本适配为准，直接制作最终图资产；完整 draw-science 的投稿、合同与精确复刻流程留给用户明确要求的对应任务，不自动加载其全部参考资料或生成工作底稿。

绘图模型和推理档位由用户决定，沿用 skill 加载时确认的 `drawing` 选择（本次指令优先，本库字段覆盖用户级设置），由宿主实际调度，不固定 Terra、Luna 或 max。缺少该角色且用户未指定时，由 agent 在聊天中集中询问并保存后再绘图；配置和交接见[模型与上下文](model_and_context_policy.md)。交接只带相关方法原文、图页和最终资产位置，沿用该绘图会话做局部修改，不附整篇阅读器或父会话。

## 适用范围

- 新绘方法总图、机制示意、算法局部变化使用科学对象示意：图中的对象和变化本身解释机制，不依赖重复小图标或一排文字框。
- 原论文实验曲线、照片、热图、数据表保留原始数据、图例、单位和条件，正确裁切并就近说明；不为统一外观而全面重绘。
- 实测数值图用原图或标准绘图库。需要补充的教学示意标明设定，不伪造实验数据或因果关系。

## 从原文直接到图

1. 读取论文相关文字与图，确定输入、核心变换、输出及真实并行/汇合/反馈；在当前思考或最终绘图源码中组织它们，无需另写图形合同、视觉计划或模块清单。
2. 用真实的网格、几何对象、矩阵/张量、样本或其他语义图元表达关键实体，必要时加入操作前后或局部放大。纯程序动作可用短标签，复杂推导留正文；图元要有意义，不是装饰。
3. 先布置对象、文字和留白，再连接明确端口。相关步骤可分区；连线不穿字、公式或无关对象，主线与反馈区分，短线也保留可见轴干。颜色、箭头头部和线宽统一，按实际科学关系选布局。
4. 复用已安装 draw-science 的必要绘制/导出工具。可编辑 .drawio 与 SVG 预览作为最终资产保留在论文 assets/；环境不适合 draw.io 时，直接生成遵守相同原则的安全 SVG，不为每篇安装一套工具。draw-science 是本机外部技能，不复制未核实许可的上游代码。通用生成器可辅助局部几何，具体字段按需查[图形专题](visual_decision_guide.md)。

## 按阅读器尺寸完成

以实际正文面板宽度设计，常用640–960px；不能将大画布缩小后仍按源码字号声称可读。普通中文说明折算后尽量不小于12px，模块名约14px以上；过密时缩短文字、重新分区或调整布局，不能靠放大按钮补救。使用对象示意与局部变化承载机制，避免仅靠文字框串联；最终资产使用论文内容标题。

主连线可从屏幕1.2–1.8px、头长6–8px起步，短边末段应容下清楚的轴干与头部。SVG显式控制marker的绝对尺寸，避免默认随线宽放大；这些是本阅读器工程默认，不是统一的期刊规范。

生成后只查看必要的本地结构/几何摘要和一次实际尺寸渲染，复用日常交付已有的两张截图额度。检查只回传错误位置、数量或短信息，不回传整篇正文或整份图源码。分组坐标造成的告警先核实实际渲染；只修真实问题，不为清零告警重画整图。正常即装配进阅读器，仅具体错误才局部修复复查；不默认评分、独立审阅、全稿复验或多轮生成。风格参考不等于精确描摹，不触发多轮严格比图。
