# 日常创作短指南

新建、续写和局部修订共用这一份指南。默认成品是讲清楚的正文、简洁方法总图、相关原图表和必要局部图；其他手册遇到对应问题再查。按“核验与主线 → 连续正文 → 插图与必要视觉 → 装配预览 → 集中审阅”推进，局部任务从相关位置进入。

## 准备

确认论文版本、PDF页数/哈希、阅读顺序和当前范围；原式与原图看实际页面核验，不只信提取文本或图注，无法辨认处留待核对。只维护一份简短底稿 `intermediate/reading-plan.md`，记来源、讲述主线、关键疑点和实际修订。方法图骨架直接保存为最终组件数据，不另抄计划或逐段媒介表。

## 正文

概览保留以下五个顶层章节及顺序，围绕“实际问题 → 方法与改动 → 实验证据 → 代价与使用条件”连续讲述；每节承接上一节留下的问题，具体机制与完整指标在详解中展开。

| 章节 | 读者应获得的认识 |
|---|---|
| 问题背景 | 从真实情境说明读者会遇到什么问题、已有办法卡在哪里，由此引出本文需要完成的任务 |
| 方法框架 | 承接任务说明为何采用这条思路，沿输入、处理与输出讲清信息如何流动、各步如何配合；前部放完整可点击方法总图，不写模块名词表 |
| 创新点 | 顺着方法指出此前难以跨过的具体障碍、本文在哪一步作了什么改变，以及改变为何有帮助，指回所属模块 |
| 实验与效果 | 接着问这些改动是否有效，讲清评测任务或benchmark、实验设计与对照，再用易懂的定性论述解释哪些观察支持什么效果、伴随什么取舍；完整数值按需保留在图表与详解 |
| 开销与论文边界 | 把效果接到实现这些改善所需的时间、算力、空间和人工代价，说明使用条件、已观察到的失败及尚待验证或解决的任务 |

详解保留原论文的大章节及其顺序，在对应位置补背景和推理，不重排为自拟教学目录。像老师带着读者理解一样把话说全：操作作用于什么对象，为什么需要它，改变或保留什么，结果如何进入下一步。用完整句子和自然的“因为、所以、因此、但是、当……时”等连接词明确因果、条件、转折与承接，少用省略对象或逻辑的碎短句。区分定义、推导、作者设计和经验观察；不把先后当因果，也不编造作者选择的唯一最优理由。

术语按领域习惯使用，保留通行英文写法；仅在有助于理解或回查原文时补充中英对照，后文保持称呼一致。

执行内置[反防御性表述](../vendor/anti-defensive-writing/SKILL.md)的基本原则：先讲结论、机制与依据；影响理解的前提和限制就近说清一次。将重复的“不能据此证明……”“这不代表……”改为有信息的正面适用范围，保留确有教学作用的概念辨析，删去无信息的免责与自我否定。专门润色时再加载完整规范。

数学先说明要描述的量与关系，再给完整原式，就地解释符号、维度/单位、运算、成立条件和用途。推导补足中间理由，区分等价、近似和新增假设，不能只列变量表。必要时用具体对象、比喻或可复算的试算接上理解；自拟数字标为教学设定，不能冒充实验。正文独立可读，长支线可就地折叠，不生成第二套“AI说人话”或隐藏公式讲解副本。

实验按真实证据讲，不强制数字排行榜。benchmark是数据/任务/协议，指标是衡量方式；标准评测、自设计对比、消融、条件变化、定性与用户研究可以并存。重要指标说明对象、含义、单位与优劣方向，比较保留条件、统计口径和取舍；不凭均值声称显著，不把成功样例当整体优势。理论/综述据实讲定理、证明或文献证据，不虚构算法与实验。

开销核查论文、补充材料及对应的作者官方仓库，优先README和相关配置/运行说明，保留出处、代码版本与运行条件。区分实测、建议与配置，一次性/每次使用、总量/新增代价，以及主机内存、GPU显存和磁盘。没有官方实现或关键数据时据实说明；未报告不等于没有代价，未验证不等于无法解决。

## 原图与必要可视化

写正文时就按图片已在预定位置的状态自然讲清内容，先完成连续论述，再将支持论点的原图表插入合适的段落边界。必要的观察、解释和隐式推理留在正文，不逐图另加读图口播。图名简短；额外的面板、颜色或局部细节提示用现有quote块紧贴图下，由组件统一使用引用式字体，不重复正文，没有补充就不加。裁切保留图号、轴、图例、单位和比较条件，不留半行图注或邻图残片；复用已核验资源，不能用自绘图替代应看的原图。

正文稳定后反查整体方法、核心创新、空间/矩阵对应及主要结果，可适当丰富有帮助的关系图、局部示意或结果对照，使重要关系与变化更容易看见。一图可解释多个问题，同一原图可在独立阅读的视图中复用；不设图数配额、不为凑图拆碎正文、不逐项写不配图理由。

方法总图以功能职责为节点，共同完成一项目标的内部小操作合并，通常先试4–7个主要模块，输入输出另计；保留真实并行、分支、反馈与创新位置，包括缓存、条件或旁路直接进入后续模块的依赖。默认只显示短模块名和必要连线；点节点/边后在底部或侧边说明职责、输入输出、传递依赖及正文入口。布局交给现有 `method_pipeline` 和辅助脚本，不手写坐标或每篇开发组件；内部计算放正文局部展开。

按本项目[可视化规范](visual_authoring_guide.md)组织演示：明确要看清的对象、关系或变化，保留可读基准状态，让必要操作产生可观察结果。其他交互只响应明确需求。公式／参数探索器仅用于确需调参观察重要变化的关键公式；简单、次要或一次试算就能讲清的关系用正文、例子或静态图。仅逐页显示文字的 `steps` 默认不生成。阅读器使用现有组件与本地资源，专门图形设计再查[制图适配](visual_authoring_guide.md)，不加载会话HTML宿主规则。

## 装配

从当前类型脚手架填正文，沿用稳定ID和固定阅读器：

    python scripts/init_reading_content.py --paper-id <id> --preset method|theory|survey|system --output <论文目录>/paper-data.js
    python scripts/prepare_method_pipeline.py --input <骨架.json> --output <组件.json>
    python scripts/deploy_reader.py --vault <库> --paper <id> --preview --preview-dir <隔离目录>

新稿保持 `schema_version:3`、`content_contract_version:"3.2"`；`overview.sections`和`explanation.sections`承载正文，全文翻译初始为 `translation:{status:"deferred"}`、顶层 `sections:[]`。数据是纯JSON赋值，不含脚本；保留证据性质及图/式/关键实验必要的内部定位，不要求普通段落来源索引。概览与详解不展示逐段或章节来源入口，保留顶部原文PDF入口。

公式使用LaTeX，HTML行内为 `\(...\)`、独立formula块为裸latex，JSON反斜杠双写；核对实际渲染。草稿按返回的隔离HTML查看，不启动正式答疑或写用户状态。字段含义不清或校验报错时只查相关合同，不预读全部schema、示例与组件目录。

## 分工与复验

只委派独立且值得并行的范围，交接相应原文、主线、必要术语/ID和输出位置，不给每人整篇历史或整套手册。独立审阅者不参与受审稿编写、装配或修正；无法独立审阅时如实记未验证。

首次交付做一次完整内容验收：从原文反查五节主线、关键隐式推理、原式/数值、原图位置及讲解、必要视觉覆盖；查看桌面/窄屏并操作本篇方法图和一次实际答疑。字段齐全、mock或脚本通过不能替代内容和真实运行。问题集中交作者修正，此后只复验问题位置、受影响及同源内容；没有新证据不重复整篇输入、全文审查或全套组件回归。底稿只记实际问题、修正与结论，不增加评分表或审批流程。

如实填写审阅者、事实核验与 `content_status:"ready"` 后正式部署：

    python scripts/deploy_reader.py --vault <库> --paper <id>
    python scripts/open_reader.py --vault <库> <id>

交付页面、启动方式和实际完成范围；实质事实错误、必要视觉缺口、答案解析失败和历史回归须先解决。旧稿不批量重写，不补造翻译或改动认可正文与锚点。

## 遇到具体问题再查

| 触发情况 | 只查相关部分 |
|---|---|
| 实验设计、指标或开销证据难以区分 | [证据专题](reading_content_guide.md)对应章节 |
| 方法模块粒度不清，或用户要求其他交互 | [图形专题](visual_decision_guide.md)；需要字段时在[组件合同](learning_support_guide.md)搜索当前type，不通读全类型 |
| 原图不足，确需新绘静态局部图 | [制图适配](visual_authoring_guide.md) |
| 数据字段、版本或来源校验异常 | [数据合同](paper_data_schema.md)对应字段 |
| 复杂数学转录、渲染或导出问题 | [数学规范](math_rules.md) |
| 用户触发全文翻译 | [翻译规则](translation_rules.md)；出现覆盖/断栏异常再查[翻译复核](translation_review_guide.md) |
| 答疑、运行或旧锚点异常 | 按[技能入口](../SKILL.md#任务入口)进入对应任务 |
