# 学术论文忠实翻译与排版规则 (Translation & Notation Rules)

## 1. 核心原则：忠实、完整、学术化

本规则吸收自成熟学术翻译规范，指导 AI 在将英文论文翻译为双语伴读页面或精读材料时，**严格忠实原文，严禁偷工减料**：

1. **逐段逐句忠实翻译**：必须完整还原原文所有段落，不得将长段落强行压缩为摘要，不得省略限定条件、比较关系、因果关系或实验参数；
2. **三视觉分离**：中文译文区、英文原文折叠区和 AI 伴读批注卡片在视觉上必须明确区分；
3. **术语首次出现规范**：
   ```text
   中文术语（English Term）
   ```
   后续段落可以只使用中文术语或领域通用英文缩写；
4. **保留英文原名的内容**：
   - 模型名称（如 DINOv2、FlexiCubes、Multi-Stream Sparse Transformer）；
   - 数据集名称（如 Mixamo、RigNet、Objaverse）；
   - 算法/库名称（如 AdamW、PyMuPDF、Playwright）；
   - 数学符号、代码变量名、参数名；
   - 引用编号与公式编号（如 Eq. (1)、Fig. 2、Table 3）。

---

## 2. 图表与公式还原规范

1. **公式高保真**：
   - 必须完整保留原论文的公式推导与编号标签（`\tag{N}`）；
   - 行内公式使用 `$ ... $`，独立公式块使用 `$$ ... $$`；
2. **表格结构完整重建**：
   - 必须使用标准 HTML `<table>` 或 GFM Markdown 表格重建；
   - 完整保留所有基线模型对比数据行与指标列；
   - **最优值必须加粗（Bold）**，次优值下划线或标注；
3. **插图与图注**：
   - 从 PDF 提取原始插图，以相对路径引用；
   - 在图下方提供中文图注，并在其后保留原英文标题对照。

---

## 3. 落地到 paper-data.js 的补充约束

1. **JSON 转义**：`latex` 与文本字段中的 LaTeX 反斜杠必须双写（原文 `\frac` → JSON `"\\frac"`）；
2. **公式定界**：`formula` 类型 block 的 `latex` 字段存**裸 LaTeX**（不带 `$$`，阅读器负责包裹渲染）；文本字段内的行内数学用 `$...$`；
3. **行内 HTML 白名单**：文本字段只允许 `<b>` `<i>` `<br>` `<a href>`；表格重建用 `table_html` 字段存完整 `<table>`（最优值 `<b>`、次优 `<u>`）；
4. **双语字段（v2.2 成本优化）**：`text_zh`（译文）必填且逐段完整；`text_en`（原文）**可选、不再全文转录**——完整原文由阅读器的"原文 PDF 侧栏"直接呈现（服务模式可用，章节联动跳页），仅关键句（定义、贡献声明等需精确对照处）可少量保留 `text_en`。保留时两字段内容必须一一对应。
