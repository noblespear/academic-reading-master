# 忠实双语翻译

仅在[主规则](../SKILL.md#工作范围主规则)规定的触发后使用本指南。翻译视图是全文对照，覆盖摘要、正文、公式、图表图注、附录（如有）与致谢；参考文献及图内标签按主规则处理。

从真 PDF 提取，核对双栏顺序、跨页段落、断词和连字。标题、图注、表格、公式不能混成伪段落；英文不得凭记忆补齐。扫描稿用宿主可用OCR/视觉工具逐页核查；不清片段明确标记并保留原区域。

英文对照保留原文措辞，包括原有语法病句；只修已经对照PDF证实的断词、连字等提取错误，不自行润色英文。中文忠实表达原意，确有原文歧义时就地标明。

先核验提取顺序，再按章节或连续段落划分，交接稳定段落ID、来源范围、必要相邻上下文和共享术语。未核验的按页切块可能割断跨栏或跨页段落；文件末尾、提取序列末尾或工具输出截断均不能证明原页缺文。翻译沿用宿主默认模型与推理设置；复杂公式、OCR与歧义交规划者核定，分工见[职责分工](authoring_delegation.md)。按原文顺序补入顶层sections，核对本次新增部分的漏译、重复及术语一致性。

提取记录保留 page/bbox，矢量图与表格可精确截图；公式必须看原区域后转录为严格LaTeX，不能以截图替代。图表编号和正文引用逐一核对。数字、正负号、单位、变量、引用编号按原文保留。

遇到断句、省略号或疑似页/栏截断，先以 page/bbox 定位原页，查看整页及该区域，再找同页相邻栏与相邻页的续文，按真实阅读顺序补齐双语并保留涉及的物理页来源。只有原区域实际不可辨认且核查后仍无法恢复时，才标记具体不清片段并保留原区域；不能用“页边截断”注释代替寻找可见续文。定位与复核步骤按需见[翻译异常复核](translation_review_guide.md)。

中文逐段忠实表达限定、否定、因果与不确定性；术语统一，专名首现给英文。不在译文加入AI解释、类比、推断、工程参数，这些放详解或回答。

两侧保留相同公式、原图、顺序和比例，图注对应翻译。中文长度不同，行高取两侧较高者；不承诺复刻 PDF 换行分页。

使用固定阅读器实际显示的字段，不自造另一套双语接口：

| 内容 | 数据字段 |
|---|---|
| 章节 | id、title_en、title_cn、page、blocks |
| 段落或小标题 | text_en、text_zh；heading也按两侧文字填写 |
| 原式 | 裸latex、eq_ref；必要原文/译文放text_en、text_zh |
| 原图 | src、caption_en、caption_zh；必要图中文字的解释放text_en、text_zh或相邻正文 |
| 结构化表格 | headers_en、headers_zh、rows_en、rows_zh、caption_en、caption_zh |

每个块有稳定id、evidence_kind:translation与覆盖真实物理页的source_refs。alt和自定义元数据不代替可见双语文字；多面板裁图分别用可显示的图块，不只把额外路径存进source_components。

对本次生成范围校验提取记录与阅读数据、图表公式、数值及引用。覆盖不全不得称全文翻译完成。原PDF保留且出处可跳页。

页数、公式编号和表格数字是定位检查，不能代替内容覆盖。核对影响理解的场景/动作/提示词、图例、表下注释、分组最优值与缩写含义是否讲清。双栏按阅读顺序拼接，跨页续句去重后保留涉及的全部物理页来源，不把后半句提前到其前提之前。

表格的粗体、下划线、分组与并列最优项可能承载比较结论，需要保留。现有表格不能忠实表达时，可在可复制数值表旁附原表裁切与短双语标记说明；不另写未经逐格对照的“赢家清单”。原文公式编号、上下标及正文邻近变量同样核对，裸伪记号须转为可显示的LaTeX。

本次翻译装配后运行 `python scripts/audit_translation_coverage.py --pdf <source.pdf> --data <paper-data.js> --output <intermediate/translation-coverage.json>`，获得按物理页和位置定位的遗漏候选；只与翻译视图英文比较，其他视图文字不抵消译文缺失。按[翻译异常复核](translation_review_guide.md)处理本次生成范围内的候选，在既有底稿简记裁定与依据。候选数与模糊匹配只用于定位，不能据此宣称完成；还需核对本次译文的中文含义与阅读顺序。修复后的复验遵循主规则，只有新证据影响已有译文时才扩大范围。
