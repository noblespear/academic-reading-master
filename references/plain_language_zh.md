# 教师式讲述与六项内容核对

讲述使读者凭已经读到的认识跟上下一步。补出专家省略的前提、对象区别、选择理由和数学关系；术语在实际问题中解释。语言长度服从理解需要，不设短句比例或评分。

正文包含必要例子、比喻和试算，长支线就地折叠；新稿不另生成AI说人话。译文仍忠实，原式、引文和数据不随润色改写。保留使结论成立的条件，删去未增加认识的重复免责和套话。来源未论证的选择如实归于作者，不补成必然最优。

## 直接审阅可见内容

独立审阅者从原文主要贡献和方法反查实际正文，不只照作者底稿核对。沿一个关键对象走过机制，检查指代、维度、索引、操作范围和下游用途；遇到“因此采用”核对前文是否真的给出了中间理由。

原图、静态图与交互分别检查是否展示所说的关系。总图检查功能模块层级，内部细节用局部图；不要求每个对象转换独立成总图节点。数学核对原式、运算和试算；本次新译内容核对顺序与覆盖。复验范围见[主规则](../SKILL.md#工作范围主规则)。

| factual_gates | 实际确认内容 |
|---|---|
| source_accuracy | 方法、原式、数字、单位和条件与来源一致 |
| evidence_separation | 论文结论、背景、作者教学解释和假设例子区分 |
| claim_scope | 主张没有扩大证据范围 |
| prerequisites | 读者理解主线所需前提和中间理由已在正文讲明 |
| formula_correctness | 符号、对象、运算、推导条件和算例准确 |
| analogy_and_example | 类比对应合理，教学设定与实测分清，例子可复算 |

保留六项作为诚实审阅声明，不生成独立风格评分或隐藏讲解副本。完成后主作者单独更新reviewer和ready；生成脚本不预置结论。浏览器未验或独立审阅缺失时如实说明，最终流程见[最终核验](final_page_checklist.md)。历史plain_language_scores仅兼容读取，不再是新稿要求。
