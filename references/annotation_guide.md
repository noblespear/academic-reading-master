# 批注与自动问答

## 用户主动批注

批注由用户划选词句、选择整块内容或继续追问时创建。3.4起取消提前批注：新内容不生成default_annotations，旧数据中的该字段也不显示、不计数、不自动加入答疑上下文。必要解释在正文中结合论文实际机制展开，概念和数学表达就地讲清。

撤下静态说明不删除SQLite里的用户问题、草稿和历史答案；过去基于说明创建的用户追问仍完整保留。用户依然可以询问任何词句、公式、图片及学习演示。

三视图共享store，各自锚定实际文字。英文offset不能套在中文上；source_refs用于跳转，不能伪装成同一选区。

键入保存草稿，点击提交自动排队。问答默认折叠且独立于正文；选区末尾气泡展开浮层。身份色固定，重叠异色并列色条/编号；状态用独立角标、文字及未读标记。

anchor含view、language、content_id、field、content_version、start/end、exact、prefix/suffix，跨段保存fragments。canonical排除按钮、浮层、数学辅助节点；offset+exact校验，必要时上下文重定位，多候选标unlocated。不得保存屏幕像素作为唯一定位。

定位与可见性分开：折叠讲解中的锚点仍然有效，但不参与高亮、气泡或跨段选区捕获。显式检查所有关闭的details祖先，不依赖缓存矩形或computed display。展开、滚动、缩放、字体及图片加载后从当前正文重新测量；数学原子只测一次，重叠色条不移动选区背景。气泡不得遮挡选区或后续正文，必要时放到旁边空白处，并以细虚线指回末端。

同一论文的新批注与追问共同延续一个宿主会话，承接之前各批注的问题与答案。概览与详解首次送入可读正文，之后只给当前问题、选区和必要新增证据；正文修改按变化块补入。进程重连从实际宿主历史恢复已送达状态，已知问答不重播。编辑递增修订并保留旧答案；删除失效未完成任务；查看新答后消未读。服务独占状态写入，不能整份JSON覆盖答案。答疑见answer_worker_guide.md，接口见bridge_protocol.md。

## 问任意词句、公式或图片

继续使用原划词批注、整块批注和追问。普通词、短语、动作或公式都可问，不要求命中词表，不另增“解释一下”按钮。公式批注带原始 LaTeX、父 block ID 和上下文；补充文本锚定父块以及 learning 的确定性字段路径。关掉说人话不失效或删除补充锚点，隐藏处的批注提示所属 AI 卡片并可就地展开。

主动答案不随说人话隐藏，翻译视图发起的答疑同样返回完整 Markdown，支持 LaTeX、小表格与代码。已存富答案仍按原路径展示；较长旧答案可以保留自己的 details 折叠。

用户提问本身说明当前理解遇到困难。普通问句也默认获得连贯解释：先回应所问，补出当前缺少的前提、因果或数学关系，按需要穿插例子、比喻或演算。3.9 答疑只生成完整 Markdown，不因公式、原图、表格或组件选区强制富答案，不自动生成图或学习组件。用户明确要演示时指出已有相关正文入口，或说明新演示需专门创作任务；当前答疑先用可用文字和例子讲清。

答疑输入范围遵循[主规则](../SKILL.md#工作范围主规则)，依据不足时通过reader_source补相关原文。选区、真实来源和明确图号／式号关联原图与公式页图，模型外核对哈希、路径及实际模型视觉能力后发送像素；资源元数据存在不代表已看到图。

本轮问题、历史与实际上下文一起检查容量；按需原文也受读取范围与容量约束，未送达范围如实记录。窗口未知时标明无法核验实际窗口。协议细节见[bridge说明](bridge_protocol.md#答疑原文与图像包)。

## 主页与批注能力对照

| 类型 | 展示/保存 | 输入与插入 | 传递与导出 |
|---|---|---|---|
| 标题、段落、列表、引用、分隔 | 共用块与渲染器 | Markdown便捷输入，保存 note_content | 队列/历史保留；可读文本回退 |
| 公式与多步推导 | 共用数学引擎，保存 latex | Markdown LaTeX 或结构化公式块 | 原式送宿主；导出保留LaTeX |
| 图像、图示 | 受管理本地资源与图注 | 引用已有图、上传或粘贴PNG/JPEG/WebP | 附件元数据和哈希保留；视觉支持由宿主核验 |
| 表格 | 结构化headers/rows，可横向滚动 | Markdown表或结构化数据 | 保存/追问保留行列，回退为文本表 |
| 代码、算法 | code/lines/algo_lines | 代码块或结构化插入 | 保存步骤，导出完整代码/伪代码 |
| 折叠、说明卡 | details/quote与共享块，旧答案保留 | 用户结构化插入；新答为 Markdown | 保存嵌套块，文本导出展开内容 |
| 学习组件 | 固定类型及配置，实例状态隔离；旧答案保留 | 引用已有 aid_id；新答只指出相关入口 | study_state快照，保存配置及教学回退 |

图表和学习组件的创作由专门任务处理；组件编辑器不是任意脚本环境。答疑继续接收选区、原图、附件和必要历史。某宿主无法直接看图时，保留图像和文字说明，并如实告知未传入像素。

## 每轮保存

user_note/answer 仍为字符串。3.9 新模型结果仅含 answer 与 sources；已有 note_content/answer_content:{version:1,blocks:[...]}、attachments:[{id,src,media_type,alt,caption,sha256}] 和 study_state JSON 对象继续兼容读取与保存。富内容存在时由其生成文本回退，避免两份相互矛盾的正文。块树、附件与状态必须贯通草稿、提交、队列、回答、history、JSON快照、重开和导出；新追问保留前轮材料，修订/结果更新不会改旧历史。

上传走认证 POST /api/assets，返回 attachment 后再引用受管理 src；不要把浏览器本地绝对路径或远程图片URL当附件。宽表、长公式和大图保持全部信息，用局部横向滚动或放大查看。关闭补充、图片加载或参数变化后重新测量几何，控件文本不进入正文选区索引。API失败保留草稿；401后刷新会话token并重连事件流。

答疑沿用宿主默认或已有会话的模型与推理设置；未显式配置的项不传入覆盖参数，用户明确指定时分别覆盖。启动及进程重连时应用一份稳定 answer_worker_guide.md，普通问题复用已经加载的会话，不再恢复线程或重复加载指南。历史由宿主管理；会话连续不等于缓存必定命中，也不表示全部原文始终在窗口内。unknown 仍只核对原任务，不自动重发；暂停与显式重建沿用原流程。
