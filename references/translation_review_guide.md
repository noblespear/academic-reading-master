# 翻译异常复核

在本次生成的翻译装配审阅，或出现断句、跨栏、来源定位异常时读取。日常翻译沿用[主译指南](translation_rules.md)，复验范围遵循[主规则](../SKILL.md#工作范围主规则)；这里的记录写入既有底稿。

## 从报告找到原文与译文

1. 确认 `intermediate/translation-coverage.json` 的 `source_pdf`、`data_path` 和SHA-256对应本次材料，按本次新生成的页/章节范围查看统计及 `candidates`，覆盖所有相关候选类型。首次生成全文时范围自然是全文；补入部分译文不重审已通过部分。
2. 对每项记下 `id`、`kind`、`page`、`bbox`、`text`。`page` 是从 1 开始的 PDF 物理页，可能不同于印在页面上的页码；`bbox` 是该提取块的左、上、右、下坐标，不一定只围住这一句。`matching_blocks` 给出最多三个有重合短语的译文块及 `source_pages`，作为查找入口。
3. 打开原 PDF 跳到该物理页，先读整页确定栏、图、表的位置，再放大 bbox 所在区域，读清前后完整句子。若用页图，先显示整页图，再显示局部截图；只看局部容易漏掉续文所在栏。常规未旋转页中，bbox 坐标原点在左上，单位为 PDF 点；若渲染成缩放页图，坐标也须乘相同缩放倍数。旋转或裁切页优先直接用 PDF 工具定位，不手算猜位置。
4. 在 `paper-data.js` 顶层 `sections` 中搜候选英文的独特短语，并打开 `matching_blocks` 对应的 ID；读取完整 `text_en`、`caption_en`、`headers_en`、`rows_en` 及相应中文和 `source_refs`。搜索结果在概览、详解或图片像素中出现，不等于译文已覆盖。报告没有匹配块时也需搜索：连字、断词或提取污染可能破坏匹配。

如 PDF 查看器不便定位，可用现有 PyMuPDF 环境渲染。把路径、物理页和 bbox 替换为当前候选的值，输出放到论文中间目录。先查看生成的整页图，再查看区域图；图必须实际打开，不能仅凭生成成功作裁定。

```python
from pathlib import Path
import pymupdf as fitz  # 旧环境可改为 import fitz

pdf_path = Path("source.pdf")
physical_page = 5
bbox = [300, 200, 550, 320]  # 示例坐标；使用报告中的实际 bbox
out = Path("intermediate/translation-review")
out.mkdir(parents=True, exist_ok=True)
with fitz.open(pdf_path) as doc:
    page = doc[physical_page - 1]
    page.get_pixmap(matrix=fitz.Matrix(2, 2)).save(out / "page.png")
    page.get_pixmap(matrix=fitz.Matrix(2, 2), clip=fitz.Rect(bbox)).save(out / "region.png")
    print(page.get_text("blocks"))  # 带位置的文本；阅读顺序仍由原页核验
```

## 断句与页/栏衔接

遇到句尾只剩主语、连接词、半句或新增省略号，按以下顺序恢复：

1. 以提取记录或候选的 page/bbox 回到原页，比较原区域与提取文字，确定是原文如此、提取缺字，还是取材/输出被截短。
2. 看同页当前栏末尾、相邻栏开头，以及图表旁的正文。通栏图表可能使提取器把右栏续文混到图注或表头附近；按版面读，不把文本文件最后一行当成整页最后一句。
3. 再看前后相邻物理页与段落边界，用句法、主题及版面确认衔接。比如左栏末尾为 “These observations suggest”，右栏开头为 “that the effect persists under noise.”，应核验后合成完整句，而非给左栏补省略号。
4. 补齐英文及中文，消除人为省略号、错误截断注释和重复续句。跨页段落在 `source_refs` 保留实际涉及的全部物理页；同页跨栏仍引用这一物理页。
5. 若原区域确实模糊或损坏，尝试放大、检查可用原 PDF/OCR 后，只标记具体不可辨认片段并保留其原区域和定位。在底稿记核查过的栏/页及尚未恢复的范围；未找到但仍可读的续文保持“待处理”。

## 三类候选逐项裁定

`ngram_coverage` 衡量候选中的英文三词组在全文翻译英文中出现的比例，`same_page_coverage` 只看来源包含该物理页的块。它们没有核验整句的对应关系。`missing_trigrams` 有助于搜缺失位置，但不是应直接拼进译文的句子；`matching_blocks` 的重复短语也可能来自别处。

| 类型 | 泛化示例 | 复核与处理 |
| --- | --- | --- |
| `unmatched_text` | 原页完整结果句未找到任何三词组匹配；也可能是 OCR 把连字拆坏。 | 在原区域读全句，搜独特短语及前后段落，确认顶层翻译是否存在其完整双语。真遗漏就补齐；如因 OCR/提取污染触发，指出原页可读内容、对应译文块和具体污染，才可裁定误报。 |
| `partial_coverage` | 缺失的后半句含常见短语，因此工具在其他段落找到部分重合；另一种情况是引用符号或断行污染使已覆盖句子匹配不足。 | 逐句比较候选、原页和匹配块，检查缺的限定词、否定、续句是否实际在同一段译文中。其他段落的共享短语不能抵消遗漏。完整句已在翻译中且差异可由具体提取问题解释，才记误报；有缺口则补两侧并核验顺序。 |
| `source_page_mismatch` | 跨页句已完整译出，来源仅登记起始页；也可能只是另一页重复措辞命中。 | 核验原页候选与所命中译文的完整内容、前后文和真实来源。确为跨页完整段落时补全 `source_refs`；实际对应另一段时继续查本段，必要时补译。若提取把重复页眉混入正文，记录原页位置及重复页眉证据；不能仅以“跨页”解释全部候选。 |

来源缺页是需要修复的定位问题，即使句子已译全也应修正。单项可能同时有内容与来源问题，修复时一起检查。

## 记录、重跑与人工检查范围

在既有底稿为每个候选保留 ID 和以下三种裁定之一：

- **待处理**：记录未确定之处与下一步要查的原页/译文块；仍有这类项时，译文覆盖审阅尚未完成。
- **确认遗漏已修**：写清补了哪段内容、译文块 ID 与来源。若只缺来源，注明“来源定位已修，内容已核验完整”，使用同一已修状态即可。
- **有证据误报**：写清原页所见、完整对应译文块及造成候选的具体差异，例如某个断行/连字、页眉或引用污染；“分数低”“候选很多”“工具误报”不是证据。

可以聚合同页同类的已确定原因，例如列出全部相关 ID、说明同一页眉在每处 bbox 中均已核验，再给共同裁定。共享原因必须已对组内每项确认；无法解释的候选单独留待处理，不能用一条笼统的“跨栏/断词”抹掉整份报告。

修复后只比较问题位置及受影响、同源候选；用page/bbox/text对照，ID或候选总数变化不能代替内容判断。新证据显示范围外有同源问题时再扩查。已经有证据裁定的误报保留简短依据，不为清零改写忠实英文，也不无依据反复跑整份报告。

底稿简记实际检查范围与未决问题。本次范围内无可抽取文本的页回到原页，扫描内容用可用OCR/视觉读取；公式、数字表格及影响理解的图内术语按原区域核对，重复小标签遵循主规则。`no_candidates_found`只表示未找到英文匹配候选，不能替代中文含义与阅读顺序检查。
