# 迁移与兼容

迁移前备份论文及状态库。保留PDF、原图、metadata、notes、旧内容和全部批注ID、quote/note/answer及时间。

先确认旧数据中已有的概览、流水线和章节讲解，将用户认可的内容直接拆分为概览与详解，保留原ID、原句、标题、顺序、列表、图表、公式、自测提示和原有讲解批注。不得默认重写、扩写或以新稿替代后把原稿藏入历史区。用户要求保留的新增图示继续保留；仅在明确要求时调整文字。

旧数据可能缺完整英文和忠实译文，重部署不等于补齐。翻译视图单独从PDF抽取并忠实翻译，不将已有通俗讲解冒充译文。数学显示修复使用独立LaTeX字段，原始内容留存。再按唯一匹配升级锚点；拆分成多个显示字段的选区保存多个片段。无法定位在列表标明，不丢问答。

v3初次导入annotations.json，已答不再调用。随后SQLite权威，JSON是快照。入口按schema_version选新旧；未迁移论文保留legacy服务。旧整份PUT不得写新版库。

迁移打包用SQLite一致性备份；含问答、任务、论文和checkpoint，不含认证/PID/端口/锁。不保证宿主session ID跨平台可用，新宿主据问答checkpoint新建会话。启动器重新生成。同名导入先核身份和冲突，保留冲突版本，不copytree直接覆盖。

仅迁移用户选择的论文，保留已有问答及时间信息；其他论文继续使用兼容入口。
