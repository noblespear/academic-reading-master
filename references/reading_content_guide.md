# 证据专题：论证、发现与适用范围

日常正文要求已并入[短指南](reader_workflow.md#正文)。仅在研究依据、解释范围或相关资源条件难以判断时查这里的对应部分。

## 论证与发现

先识别作者要回答的问题与实际采用的研究路径，再解释依据如何支持结论。下表供按需选择，混合研究可结合使用。

| 研究依据 | 需要进一步核对的区别 |
|---|---|
| 实验与定量分析 | 研究对象、数据来源、样本与指标；对照、统计口径及不确定性；相关关系与因果识别是否区分 |
| 观察、访谈、田野与案例 | 材料和参与者如何选择，情境与研究者位置，分析或编码如何形成解释，反例与不同声音如何处理 |
| 文本、史料与档案 | 版本、来源与语境，材料的代表性和相互印证；原文记载、作者解释与读者推断是否区分 |
| 理论与概念论证 | 定义、前提、推理步骤、反例与回应；结论成立于什么假设，是否超出已经论证的范围 |
| 文献综述与综合 | 检索或选材范围、纳入依据、分类方式及证据质量；共识、分歧和缺口分别由哪些文献支持 |

概览讲主要发现及其依据，详解在原章节解释完整推理。指标是代理量时说明它与研究问题的联系和局限；定性解释依材料、语境与论证判断，不强行转换为数值排名。原文未使用的研究设计或分析程序不补写成已完成工作。

### 涉及实验比较时

标准评测核对数据、划分、任务和协议；自设计对照说明控制条件；消融辨明改变了哪些因素；规模与效率分析保留条件及取舍。误差、重复次数和统计检验只按原文报告，不从平均值排序补造显著性，不以成功样例代表总体效果。

## 适用范围与局限

区分研究前提、材料或样本覆盖、理论成立条件、情境限制、作者承认的问题与未讨论的范围。新增读者判断标明依据。尚未讨论不等于结论已经被推翻；局部材料能支持的解释也不自动推广到所有群体、时期或语境。

综述重点核对覆盖范围与文献选择；理论研究核对前提和反例；实证研究核对样本、情境及推断范围；文本与史料研究核对材料可得性、版本、语境和其他解释。只展开影响本文结论或用户问题的限制，不罗列无关缺项。

### 涉及实施或资源条件时

仅当资源需求影响研究理解，或用户要求评估实施可行性时，说明时间、设备、算力、材料获取与人工代价。查论文及相关补充；存在官方代码且与问题相关时，再沿论文或作者项目页查对应文档、配置或脚本，注明实际版本和条件。

设备型号、batch size和迭代数属于配置，不等于最低硬件、实测耗时或费用；模型文件大小不等于运行显存。区分实测、建议与配置，理论复杂度与运行测量，一次性与重复使用、总量与新增代价。论文与仓库数值有差异时分别说明已知条件。关键数据缺失时说明实际来源范围，不推算成零开销。
